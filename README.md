# 捕鱼达人 — HTML5 Canvas 游戏

一个完整的HTML5 Canvas捕鱼主题游戏，包括鱼群、武器系统、升级商店与饵料机制。

## 运行方式

在浏览器中打开 `index.html`（双击或通过本地开发服务器）。

## 游戏玩法

- **捕捞鱼群**：点击画布或点击"发射导弹"按钮发射导弹；捕获不同种类的鱼获得金币。
- **渔网**：点击"投掷渔网"可在屏幕中央投放渔网，覆盖范围内的鱼被一次性捕获。
- **鱼群**：场景中有 4 种鱼（小鱼/中鱼/大鱼/稀有鱼），价值与难度递增。
- **冷却与弹药**：导弹与渔网各有独立的弹药与冷却系统，可通过商店升级获得回复。

## 商店升级系统

开启游戏时点击"🛍️ 商店"按钮（或 ESC 关闭），可购买以下永久升级：

| 升级项 | 价格 | 效果 |
|--------|------|------|
| **🎯 穿透弹** | 300 | 导弹能穿透多条鱼（当前可穿透 3 条鱼） |
| **💥 爆炸弹** | 350 | 导弹命中处触发范围爆炸伤害 |
| **🌊 渔网扩容** | 200 | 每次购买增加渔网半径 +60px |
| **🪢 饵料包** | 80 | 购买饵料，可在游戏中投放诱饵吸引鱼群 |

所有升级会自动保存到浏览器 `localStorage`，重新打开游戏后保持生效。

## 游戏特性

- **精致的鱼精灵**：使用 SVG 渐变和阴影效果绘制，各种鱼具有独特的外观与颜色。
- **爆炸粒子系统**：爆炸弹命中时会产生粒子效果，增强视觉反馈。
- **饵料吸引机制**：投放饵料后，周围 300px 内的鱼会逐渐被吸引向饵料位置。
- **动画背景**：海底环境包含渐变、浮游粒子与海底装饰，增强沉浸感。
- **WebAudio 音效**：发射、命中、金币入账等事件都有合成音效反馈。
- **移动端适配**：支持触控与鼠标输入（可根据需要进一步优化）。

## 核心类与逻辑

- **Fish**: 鱼的类，每只鱼有速度、类型、浮动动画、碰撞半径。
- **Projectile**: 导弹，支持穿透与爆炸模式；绘制为旋转三角形以显示方向。
- **Net**: 渔网，绘制为扩张圆形；可通过升级增加半径。
- **Explosion**: 爆炸，使用粒子系统渲染，并对范围内鱼造成伤害。
- **Particle**: 爆炸粒子，具有物理模拟（重力）与淡出效果。

## 数值配置（可调整）

在 `src/main.js` 中可修改以下参数调整游戏难度与节奏：
- `fishTypes` 数组：鱼的速度、价值、半径等属性。
- `missileCooldown` / `netCooldown`：武器冷却时间。
- `missileAmmo` / `netAmmo`：初始弹药数量。
- 爆炸半径、穿透次数、饵料吸引范围等。

## 性能优化

- 使用 `requestAnimationFrame` 驱动游戏循环，帧率自适应。
- 碰撞检测采用简单的圆形距离算法（O(n²)）；大量鱼群时可优化为空间划分。
- Canvas 渲染优化：复用渐变对象、减少状态改变。
